# PWX-0005: Default password length of 16 characters

**Status:** Accepted
**Date:** 2026-11-17

## Context
The default length determines the strength of most generated passwords,
since many users never change it. Too short weakens security; too long risks
hitting sites with low maximum lengths.

## Options considered
1. **12 characters.** A common minimum, with a thinner safety margin.
2. **16 characters.** Strong, and within nearly every site's limit.
3. **20 characters.** Stronger, but occasionally exceeds site limits.

## Decision
Default to 16 characters.

## Consequences
- With all four character types enabled, the default password has roughly
  100 bits of entropy.
- Nearly every site accepts the default length.
- Users can still adjust the length for sites with stricter or looser rules.
