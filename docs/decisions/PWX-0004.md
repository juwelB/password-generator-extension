# PWX-0004: Use a safe subset of symbols

**Status:** Accepted
**Date:** 2026-11-17

## Context
Some websites reject certain symbols in passwords, such as quotes,
backslashes, and spaces. A generated password that a site rejects is a broken
experience.

## Options considered
1. **All printable ASCII symbols.** Maximum entropy per character, but more
   site rejections.
2. **A safe subset:** `!@#$%^&*-_=+`. Accepted by almost every site.
3. **A user-editable symbol list.** Most flexible, but adds UI and validation
   work.

## Decision
Use the safe subset (option 2): `!@#$%^&*-_=+`

## Consequences
- Generated passwords are accepted by almost every site.
- Slightly lower entropy per character, offset by the 16-character default
  (see PWX-0005).
- A user-editable list can be added later through a new ADR.
