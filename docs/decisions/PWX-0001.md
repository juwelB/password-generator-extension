# PWX-0001: Use TypeScript, Vite, and Manifest V3 for the v1 tech stack

**Status:** Accepted; linting choice superseded by PWX-0011
**Date:** 2026-11-17

## Context

The project is a password generator browser extension, built as a portfolio
project. Version 1 (MVP) is a popup that generates and copies passwords.
The stack needs to be reliable, easy to test, and look professional to
reviewers, without adding complexity the MVP doesn't need.

## Options considered

1. **Plain JavaScript, no build step.** Simplest setup, but no type checking.
2. **TypeScript compiled with Vite.** Type safety and a small build step.
3. **TypeScript with a UI framework (React/Vue).** More tooling than a
   small popup needs.

## Decision

- **Platform:** Manifest V3, targeting Chrome and Edge from one codebase.
- **Language:** TypeScript.
- **Build tool:** Vite.
- **UI:** Plain HTML and CSS, no framework.
- **Testing:** Vitest.
- **Code quality:** ESLint and Prettier.
- **CI:** GitHub Actions runs tests on every push.

## Consequences

- Type errors are caught before the code runs.
- A build step is required; the extension loads from the `dist/` output.
- The popup stays lightweight with no framework dependencies.
- Vitest runs in Node, which provides `crypto.getRandomValues()`, so the
  generator can be tested outside the browser.
- Firefox support would need small manifest changes in a later version.
