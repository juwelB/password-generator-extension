# PWX-0006: Auto-generate a password when the popup opens

**Status:** Accepted
**Date:** 2026-11-17

## Context
The main reason to open the popup is to get a password. Requiring a click
on a Generate button adds a step to every single use.

## Options considered
1. **Auto-generate on open.** The password is ready immediately.
2. **Wait for a Generate click.** One extra click every time.

## Decision
Generate a password as soon as the popup opens.

## Consequences
- The common case takes one click: open the popup, then copy.
- A password is generated even if the user closes the popup without using it.
  This is harmless, since passwords are never stored (see PWX-0002).
- The Regenerate button remains available for a fresh password.
